# Vetor de Números em Java

## Descrição

Programa que lê 5 números inteiros e realiza as seguintes operações:

- Maior número par do vetor
- Menor número ímpar do vetor
- Soma de todos os valores
- Média dos valores

Caso não exista nenhum número par ou ímpar, o programa informa ao usuário.

## Como executar

1. Compile os arquivos a partir da pasta `src`:
   ```
   javac vetores/service/VetorService.java vetores/app/ProgramaVetor.java
   ```
2. Execute a classe principal:
   ```
   java vetores.app.ProgramaVetor
   ```

## Exemplo de uso

Entrada: `5, 8, 3, 10, 7`

Saída:
```
Maior par: 10
Menor ímpar: 3
Soma: 33
Média: 6,60
```
